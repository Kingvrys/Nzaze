# 🏨 Nzaze - Guest Tracking & Administration Portal

**Nzaze** is a robust, role-based enterprise web application built for property management, secure staff authentication, and guest tracking. It features dedicated control centers for administrators and tailored portals for guests.

---

## 🚀 Features

* **Role-Based Access Control (RBAC):** Secure authentication separating Administrator privileges from Guest portal views.
* **Admin Dashboard:** Comprehensive management controls for tracking guests, property management, and viewing real-time system states.
* **Dedicated Guest Portal:** Tailored interface for guests to view announcements, stay guidelines, and reservation details.
* **Session Management:** Secure HTTP session handling via Jakarta EE Servlets and JSP.
* **Local Development & Deployment:** Powered by Apache Maven and Embedded Jetty for fast iteration and local testing.

---

## 🛠️ Tech Stack

* **Backend:** Java (Jakarta EE), Servlets, JSP (JavaServer Pages)
* **Build Tool:** Apache Maven
* **Server Container:** Embedded Eclipse Jetty / Apache Tomcat
* **Database:** MySQL
* **Frontend:** Bootstrap 5, HTML5, CSS3

---
